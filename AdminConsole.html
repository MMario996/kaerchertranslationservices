Google Drive Export ("Save to Drive")
Low impact – opt-in feature per user

Lets users save translated files directly into their own Google "My Drive" (with the option to convert Word/Excel/PowerPoint files to Google Docs/Sheets/Slides), instead of only downloading to their computer.

This requires a one-time OAuth Client ID + Client Secret (type "Web application") created in the Google Cloud Console project linked to this script (Apps Script editor → Project Settings → "Google Cloud Platform (GCP) Project" shows which one). Under "Authorized redirect URIs" add https://script.google.com/macros/d/{SCRIPT_ID}/usercallback (Script ID from Project Settings) – not "Authorized JavaScript origins" (that path doesn't work for this app, see DriveSaveConfig.gs). Paste the Client ID and Secret below.

settings_applications Advanced Settings (Script Properties)
Critical – System Configuration

These are the raw system variables that control how the application works. Only edit if you know what you're doing.

  • ACCESS_SHEET_ID / OPS_SHEET_ID: Google Sheet IDs for the config and uploads databases.
  • ADMIN_EMAILS: Comma-separated admin email addresses.
  • PHRASE_API_TOKEN: API token for Phrase TMS (masked for security).
  • • Protected keys cannot be deleted, only edited.
  • ⚠ Click the eye icon to temporarily reveal masked values.

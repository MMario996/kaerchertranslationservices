{"5818281650204":"\u003cp>Projects consist of at least two languages which are called locales in the context of internationalization. A locale defines a user language and contains language and country related parameters. Many languages can be added to project to reflect all the variants and country regions to supported by the software project.\u003c\/p>\n\u003cp>The Languages tab on the project page provides an overview of all languages added to the project, including the translation status of keys for each language. Clicking a language's translation-status count (e.g. untranslated or unverified) opens the Editor pre-filtered to just those keys for that language. Use the options at the top of the list to search for a specific language or filter by Language type to display only the project's main or default language.\u003c\/p>\n\u003cp>\u003cstrong>Default locale\u003c\/strong>\u003c\/p>\n\u003cp>A default locale is automatically set when the first language is added to the project. The default locale can be changed when adding or editing languages of a project.\u003c\/p>\n\u003cp>By default, the source language for translations is set to the default locale. If required, a different source language can be selected when translating keys in the \u003ca href=\"#\/a\/5822638157340\" data-kb=\"5822638157340\">translation editor\u003c\/a>.\u003c\/p>\n\u003cp>\u003cstrong>Main language\u003c\/strong>\u003c\/p>\n\u003cp>A main language is a language designated as an authoritative source for content changes in a project. When a translation is updated in a main language, translations of the same key in other languages are automatically marked as \u003cem>unverified\u003c\/em>. This indicates that they may need to be \u003ca href=\"#\/a\/5784094755484\" data-kb=\"5784094755484\">reviewed\u003c\/a>.\u003c\/p>\n\u003cp>A language can be marked as main by selecting Mark as main language in the Review tab when \u003ca href=\"#\/a\/5818281650204\/add-a-language\" data-kb=\"5818281650204\">adding or editing a language\u003c\/a>.\u003c\/p>\n\u003ch3 id=\"h-add-a-language\">Add a Language\u003c\/h3>\n\u003cp>To add a language to a project, follow these steps:\u003c\/p>\n\u003col>\n\u003cli>\u003cp>Click Add language \u003cimg src=\"https:\/\/support.phrase.com\/hc\/article_attachments\/30682492983708\" alt=\"Add a Language\" loading=\"lazy\" referrerpolicy=\"no-referrer\">on the Languages tab of any project.\u003c\/p>\n\u003cp>The Add language window opens.\u003c\/p>\n\u003c\/li>\n\u003cli>\u003cp>Select a name for the language.\u003c\/p>\n\u003cp>Be specific with the language name to reduce confusion between variants and avoiding having to rename if variants are later added.\u003c\/p>\n\u003c\/li>\n\u003cli>\u003cp>Select the language code from the drop-down list.\u003c\/p>\n\u003cul>\n\u003cli>\u003cp>All projects have a default locale with it being English (en) in most cases. If a different default language is required, it can be selected from the dropdown list on the Advanced tab.\u003c\/p>\n\u003c\/li>\n\u003cli>\u003cp>When translations are requested but not found, a fallback language can be defined on the Advanced tab. This language is used for missing translations in \u003ca href=\"#\/a\/5804059067804\" data-kb=\"5804059067804\">OTA\u003c\/a> distributions.\u003c\/p>\n\u003cp>Fallbacks will not work on \u003ca href=\"#\/a\/12949643568412\" data-kb=\"12949643568412\">linked keys\u003c\/a>.\u003c\/p>\n\u003c\/li>\n\u003c\/ul>\n\u003c\/li>\n\u003cli>\u003cp>Set \u003ca href=\"#\/a\/5784094755484\" data-kb=\"5784094755484\">review\u003c\/a> options from the Review tab.\u003c\/p>\n\u003c\/li>\n\u003cli>\u003cp>Click Save.\u003c\/p>\n\u003cp>The specified language is added to the project.\u003c\/p>\n\u003c\/li>\n\u003c\/ol>\n\u003cp>Languages can be deleted from the More options \u003cimg src=\"https:\/\/support.phrase.com\/hc\/article_attachments\/30682430390556\" alt=\"Open More Menu\" loading=\"lazy\" referrerpolicy=\"no-referrer\"> menu beside the selected language in the Languages tab.

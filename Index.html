Translation Services ? User Guide

Here you will find detailed instructions on how to request translations, upload files, and manage your projects.

chat 1. Initial Setup & Google Chat Notifications

The system can automatically notify you via Google Chat ? as soon as your project is submitted, the translation is ready, or a deadline is approaching.

One-time setup (3 steps):

1
Activate the bot: Open Google Chat, search for the bot "Translation-Services" and send it any message (e.g. "Hello"). This registers your account.
2
Enable notifications: Click the tune icon here (top right) ? set Google Chat Notifications to ON ? Save.
3
Submit your first project: When you submit your first project, you will automatically receive a confirmation message in Google Chat. From then on, you'll be notified whenever a translation is complete.

?? The bot is read-only ? it only sends notifications and does not respond to messages.

post_add 2. Submitting a New Project
Please follow the steps in order ? the form unlocks each field sequentially:
1

Select Template

Choose the appropriate template for your department from the dropdown. Use the search field to filter the list quickly. The template defines the translation workflow and the available language combinations.

2

Select Source Language

Choose the language of your original document. The target language field will only unlock after this selection ? since each template defines its own language combinations.

3

Select Target Language(s)

You can select multiple target languages simultaneously. For each language, the system creates a separate job. The final download will be a ZIP file containing all translated documents with correct filenames.

4

Set Project Name

The name is automatically taken from the filename. For Marketing projects, always include: Project number / Project name / Name of submitter. Multiple files will be named "File 1, File 2, ?".

5

Due Date & Note (optional)

Select a desired completion date ? the system sets the time automatically to 12:00 PM. Use the Note field for specific instructions to the translator, such as tone, target audience, or formatting requirements.

bookmark 3. Project Presets ? Save Time
If you regularly use the same template and language combination, you can save it as a preset and load it with one click next time.
save

Save a Preset

Configure the form as desired (template, languages, note) and click Save next to the presets dropdown. Give it a meaningful name, e.g. "DE?EN+FR CORP Standard".

upload

Load a Preset

Select a saved preset from the dropdown at the top of the form and click Load. The template, languages and note are filled in automatically. Then simply upload your file and submit.

delete

Delete a Preset

Select the preset in the dropdown and click Del. Presets are user-specific ? other users cannot see your presets.

cloud_upload 4. Uploading Files (PC & Google Drive)
You can upload files directly from your computer or select them from Google Drive. There are two clearly defined file categories:

Main Files

The documents that need to be translated. Multiple files are supported.

  • Allowed: .docx, .xlsx, .pptx, .idml, .txt, .xml, .html and more.
  • Not allowed: PDF as main file! PDFs cannot be processed for translation. Please upload the original editable format.

Reference Files

Context material for the translator ? not edited or translated.

  • All formats allowed ? including PDFs.
  • Ideal for visual PDFs, style guides, old brochures, glossaries or briefing documents.
Google Drive tip: You can mark files as favourites (?) in the Drive browser for even faster access next time.
manage_search 5. Managing Projects ("My Projects")
The "My Projects" tab contains all your submissions. Switch between table view and calendar view (by due date), and use filters and search to find projects quickly.
cloud_download

Download Translation

Once the status shows COMPLETED or DELIVERED, the download button appears. For multiple target languages or files, a ZIP file is created automatically with each translated file correctly named.

edit_note

Send Note to Translator

Use the note icon to add a message directly in Phrase TMS even after submission. Ideal for follow-up questions or clarifications that arise after upload. The note is saved and visible to the translator.

timeline

Track Status Timeline

The timeline icon opens an overview of all processing steps for your project ? from UPLOADED to DELIVERED. You'll also find the direct link to your project in Phrase TMS here.

share

Share Project with a Colleague

Enter a colleague's email address. They will see the project in their own "My Projects" tab, can track the status and download the final files. They also receive a Google Chat notification.

content_copy

Clone Project

Copies the project name into a new form. Useful when an updated version of the same file needs to be submitted in the same languages. Template and languages must be selected again.

delete

Cancel Project

Cancellation is possible as long as the project has not yet reached the status COMPLETED or DELIVERED. Cancelling also removes the project from Phrase TMS.

archive 6. Archive

Completed projects that are older than 7 days after the last download are automatically moved to the archive. This keeps the "My Projects" list clear and manageable.

Click "Show Archive" in the project list to view archived projects. Archived projects can still be viewed but can no longer be edited.

alarm 7. Automatic Deadline Reminder

If a project has a Due Date set and is not yet completed 24 hours before the deadline, you will automatically receive a reminder message in Google Chat. This ensures you never miss a deadline.

Prerequisite: Google Chat Notifications must be enabled (see step 1).
